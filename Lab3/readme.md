# HTTP Module

It is built in Node.js Module which allows developer to create web server andweb server and web client without installing any external package.
One of the most important module in Node.js, originally designed for building scalable network application and web servers.

2.handle client request 
3.Build REST APIs
4.Non-Blocking I/O
